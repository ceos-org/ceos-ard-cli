# Fonts

[Carlito](https://github.com/google/fonts/tree/main/ofl/carlito) is embedded in the HTML documents, see [OFL.txt](OFL.txt) for its license.

The files contain all characters and features of the original fonts except for Cyrillic, which keeps the documents smaller.
They were created with the `subset` module of [fontTools](https://github.com/fonttools/fonttools) (`flavor="woff2"`, `layout_features=["*"]`).
